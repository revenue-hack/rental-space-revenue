# Rental Space Revenue

レンタルスペース運営者向けのCodex／Claude対応Agent Skillです。接続済みメールに届く予約通知と、アップロードされた精算明細を予約ID単位で照合し、対象月の売上・媒体手数料・手数料控除後金額を媒体別およびスペース別に集計します。

このリポジトリの`SKILL.md`はCodexとClaudeの両方が読み込める共通のスキル本体です。Claude専用の`CLAUDE.md`へ同じ手順を複製する必要はありません。

## このスキルが行うこと

- 対象月に実際に利用された予約を「利用日基準」で抽出します。メール受信月や予約申込月では集計しません。
- 対象年月が指定されていない場合は、検索を始める前に「何年何月の利用分を集計するか」を必ず確認します。
- 対象月より最大1年前までメールを遡り、早期に入った予約も対象にします。
- 対象予約について、変更、延長、キャンセル、返金、精算に関する後続通知を最新の状態まで確認します。
- 同一媒体内では予約IDまたは予約Noを主キーにし、1予約で複数届く通知を統合します。
- 予約変更は承諾済みの内容だけを反映し、未承諾の変更リクエストは売上に加えません。
- 延長通知が累計額を示す場合は最新累計額を採用し、増分額を示す場合だけ元の金額へ加算します。
- キャンセルは確定したキャンセル料または返金額を反映します。返金結果が不明な予約は確定売上から除外して要確認にします。
- 媒体ごとの掲載名や住所を照合し、同じ施設を共通のスペース名へ名寄せします。不確実なものは自動で混ぜず、未分類として残します。
- 媒体別、スペース別に、予約数、確定売上、手数料、手数料控除後金額を集計します。
- 予約明細と通知履歴を残し、集計金額を元のメールや精算明細まで追跡できるようにします。
- 金額へ影響する情報が不足している場合は推測せず、対象予約IDと確認したい内容をユーザーへ質問します。

ここでいう「手数料控除後金額」は、確定売上から媒体・決済・振込に関する確認済みまたは推定手数料を引いた金額です。家賃、光熱費、清掃費などの運営経費は含みません。

## 対応媒体とデフォルト手数料

実際の精算明細、予約固有の優遇条件、個別契約が確認できる場合は、そちらを優先します。確認できない場合のデフォルトは次のとおりです。

| 媒体 | 条件 | デフォルト手数料 |
| --- | --- | ---: |
| インスタベース | 時間単位・人数単位プラン | 35% |
| インスタベース | 1日単位プラン | 20% |
| スペースマーケット | 通常予約 | 30%相当 |
| スペースマーケット | 同じ予約のメールに「お得意様割」と明記 | 5% |
| Yoyappin | 表示上のシステム利用料 | 35%（税抜） |
| Yoyappin | 計算に使う税込実効率 | 38.5% |
| カシカシ | CSVまたはPDFの精算明細 | 明細記載の実額を使用 |

Yoyappinは、35%のシステム利用料に対して消費税10%がかかる前提のため、売上に対する実効控除率を38.5%として計算します。

スペースマーケットの「お得意様割」は、同じ予約IDに紐づく現在有効なメール本文で確認できた予約だけに5%を適用します。同じ月や同じスペースの別予約へ一括適用しません。

## カシカシの取込方法

カシカシは、管理画面から対象期間の支払明細をCSVまたはPDFでダウンロードし、会話へアップロードしてください。このスキルが明細に記載された予約ID、利用日、スペース名、売上、成約手数料、支払金額を読み取ります。

振込手数料がある場合は店舗へ勝手に配賦せず、共通費として分けて表示します。予約ごとの支払金額合計から振込手数料を引いた金額が支払予定額と一致するか確認します。

カシカシはCSVまたはPDFがアップロードされた場合だけ計算します。予約ID、成約手数料、振込手数料、支払予定額を確認できない暫定情報から、カシカシの売上や手数料を推定しません。

カシカシの明細が未提出でも、インスタベース、スペースマーケット、Yoyappinの集計は先に進められます。その場合はカシカシを含まない暫定集計であることを明記し、集計途中または結果報告時に、対象期間のカシカシCSVまたはPDFをアップロードすれば追加集計できることを案内します。

## Codexで使う

このリポジトリをCodexのスキルディレクトリへ配置します。

```bash
git clone https://github.com/revenue-hack/rental-space-revenue.git ~/.codex/skills/rental-space-revenue
```

その後、次の手順で実行します。

1. 予約通知が届くメールアカウントを接続します。
2. `$rental-space-revenue` を指定し、集計対象年月を伝えます。年月がなければ、スキルが検索前に質問します。
3. スキルが読み取り専用のプロフィール確認などを行い、メールコネクターが実際に接続済みか確認します。未接続または対象アカウントが不明な場合は、集計を始めず接続・確認を依頼します。
4. カシカシを含める場合は、対象月のCSVまたはPDFをアップロードします。後から追加して再集計することもできます。
5. 不明なキャンセル、手数料、店舗名寄せがある場合は、スキルが予約IDを示して確認を求めます。

## Claudeで使う

ClaudeのAgent Skillsも、YAMLフロントマター付き`SKILL.md`と必要に応じたスクリプト・参照資料で構成されます。このリポジトリは同じ形式に対応しています。

### Claude Code

個人用スキルとして配置する場合：

```bash
git clone https://github.com/revenue-hack/rental-space-revenue.git ~/.claude/skills/rental-space-revenue
```

特定プロジェクトだけで使う場合は、そのプロジェクト内へ配置します。

```bash
git clone https://github.com/revenue-hack/rental-space-revenue.git .claude/skills/rental-space-revenue
```

Claude Codeは`SKILL.md`の`name`と`description`からスキルを検出し、依頼内容が一致したときに本文と必要な参照ファイルを読み込みます。明示的に依頼する場合は、スキル名`rental-space-revenue`を指定してください。

### claude.ai

リポジトリのスキルディレクトリをZIP化し、claude.aiのSettingsからCustom Skillとしてアップロードします。Custom Skillsとコード実行が利用できるプラン・設定が必要です。

### Claude API

Custom SkillとしてSkills APIへ別途アップロードし、Code Execution toolとともに使用します。Claude APIのスキル実行環境にはネットワークや実行時パッケージ導入の制約があるため、メール取得用ツールとPDF解析依存関係を事前に用意してください。

Claudeの公式仕様は[Agent Skills overview](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)を確認してください。

### メール接続について

このスキル自体にはGmailの認証情報を含めません。CodexまたはClaude側で、メールを検索・閲覧できるGmailコネクタやMCPツールを接続してください。メール接続がない環境では、予約通知をエクスポートして入力として渡す必要があります。

エージェントは集計開始前に、メール検索・閲覧機能が存在することだけでなく、プロフィール取得などの無害な読み取り操作で対象メールボックスへ実際にアクセスできることを確認します。接続できない場合や対象アカウントが不明な場合は、その事実を明示してユーザーへ接続またはアカウント確認を依頼します。

実行手順：

1. 予約通知が届くメールアカウントまたはメール閲覧ツールを接続します。
2. エージェントが接続状態を確認します。確認できない場合は集計を止め、必要な接続方法を案内します。
3. 集計対象月と利用日基準であることを伝えます。
4. カシカシを含める場合は、対象月のCSVまたはPDFをアップロードします。
5. 不明なキャンセル、手数料、店舗名寄せがある場合は、エージェントが予約IDを示して確認を求めます。

呼び出し例：

```text
rental-space-revenueスキルを使って、先月利用分の売上を媒体別・スペース別に集計してください。
```

## 補助スクリプトは何のためにあるか

補助スクリプトは、利用者が単独で毎回実行することを前提にしたアプリではありません。CodexやClaudeなどのAIエージェントが、定型処理を再現可能かつ検証しやすく実行するために使います。

### `scripts/parse_kashikashi.py`

アップロードされたカシカシのCSVまたはPDFを読み取り、予約ID、利用日、スペース名、売上、手数料、支払金額、振込手数料、支払予定額を正規化します。PDF読込には`pypdf`を使用します。

```bash
python3 scripts/parse_kashikashi.py statement.pdf --output normalized.json
```

### `scripts/reconcile_reservations.py`

AIエージェントがメールから抽出した予約イベントを、媒体名と予約IDの組み合わせで統合します。確定、変更承諾、延長、キャンセル、返金の順序を処理し、予約ごとの最終的な確定金額と参照元IDを出力します。

```bash
python3 scripts/reconcile_reservations.py events.json --output reservations.json
```

AIエージェントは、スクリプトの出力をそのまま信用するのではなく、メール本文、予約ID、精算明細の合計と照合してから報告します。Gmailへの接続・検索そのものをPythonスクリプトが行うわけではありません。

## 出力

通常は次の内容を含む表計算ファイルを作成します。

- 媒体別集計
- スペース別集計
- 予約ID別明細
- 適用した手数料率と根拠
- 重複・変更・延長・キャンセルを確認できる通知履歴
- 未確認事項の一覧

## プライバシーとデータ管理

この公開リポジトリには、予約メール、顧客情報、メールアドレス、電話番号、住所、予約ID、実際のスペース名、精算明細、売上金額、集計結果、生成した表計算ファイルを保存しません。

入力メール、アップロードされたCSV/PDF、中間抽出データ、集計結果は実行時の作業データです。リポジトリへコミットしないでください。`.gitignore`ではPDF、表計算ファイル、環境変数ファイル、出力ディレクトリなどを除外しています。
